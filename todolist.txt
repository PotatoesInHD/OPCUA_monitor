--- see bewlow for boots tips for reading a config file.
An external configuration file is a massive win when packaging with PyInstaller.

Once your script is compiled into an .exe, modifying a Python constant requires rebuilding the entire binary. With an external config file sitting right next to the executable, anyone can change the PLC IP address, node IDs, directory paths, or heartbeat intervals using Notepad without recompiling.

File Format Tips
While a plain .txt works, two built-in Python options make this effortless:

1. .ini format via Python's built-in configparser
This is standard for Windows automation tools:

# config.ini
[plc]
url = opc.tcp://192.168.1.50:4840
heartbeat_node = ns=2;s=CLICK.Heartbeat
trigger_node = ns=2;s=CLICK.FileUpdated

[paths]
mdb_dir = C:\PlantData
mdb_filename = production.mdb

Python reads it with zero external dependencies:

import configparser

config = configparser.ConfigParser()
config.read("config.ini")

url = config.get("plc", "url")

2. .json format via Python's built-in json
Also zero dependencies, maps directly to Python dictionaries:

{
  "plc_url": "opc.tcp://192.168.1.50:4840",
  "heartbeat_node": "ns=2;s=CLICK.Heartbeat",
  "trigger_node": "ns=2;s=CLICK.FileUpdated"
}

The PyInstaller Gotcha for Config Files
When bundled with PyInstaller, os.getcwd() might point to wherever the terminal was opened, not where the .exe lives.

To always load the config file from right next to the .exe:

import sys
import os

if getattr(sys, 'frozen', False):
    # Running inside PyInstaller bundle
    app_dir = os.path.dirname(sys.executable)
else:
    # Running as normal .py script
    app_dir = os.path.dirname(os.path.abspath(__file__))

config_path = os.path.join(app_dir, "config.ini")

That ensures it always finds config.ini in the exact same folder as the .exe!
